# Traduções em português

Crie um arquivo por livro, com o mesmo `slug` de `src/content/library.ts` (ex.: `bereshit.json`):

```json
{
  "translator": "Nome do tradutor e editora",
  "license": "Autorização escrita de AAAA-MM-DD",
  "approvedBy": "Rabino ou Beit Din responsável",
  "chapters": { "1": ["versículo 1", "versículo 2"] }
}
```

A tradução só aparece, lado a lado com o hebraico, quando o número de versículos do capítulo é idêntico ao do original.
