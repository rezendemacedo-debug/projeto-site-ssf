# Segurança

Não abra issue pública para relatar uma falha. Fale com a direção da Sinagoga Sem Fronteiras pelo WhatsApp que consta no site, descrevendo o problema e como reproduzi-lo. Responderemos o quanto antes e daremos crédito a quem relatou, se desejar.

O código nunca deve conter segredos (`.env`, chaves, bancos de dados) nem dados de membros.
